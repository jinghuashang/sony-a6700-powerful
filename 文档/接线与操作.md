# 接线与操作顺序

适用范围：一台 A6700 2.00、RP2040 Pico 兼容板、PIO 开漏 v2。Pico 2／其他机型／其他固件未验证。以下为电气节点示意，**不是实机接线照片**；没有照片时不要凭杜邦线颜色或板子外形猜引脚。

## 材料

| 材料 | 数量 | 要求 |
|---|---:|---|
| RP2040 Pico 兼容板 | 1 | 能引出 GP28 与 GND；GP28 是 GPIO 编号，不是物理第 28 脚 |
| USB-C 公头 24 针引出测试板 | 1 | 引出 VBUS、信号 GND、A5、B5、A 侧 D−，不能是仅供电板 |
| USB-A 四针引出板或已确认极性的供电线 | 1 | 从 Mac／扩展坞取 5V 与 GND；数据脚留空 |
| 约 56kΩ 电阻支路 | 2 | 两路独立，一路给 CC1、一路给 CC2 |
| 470Ω 电阻 | 1 | 串在 GP28 与相机侧 D− 之间 |
| 数据线、连接线、绝缘材料 | 按需 | 已验证方案用同一根 USB-C 数据线先连 Pico，再移到相机 |
| 相机、电池与 Mac | 现有 | 当前操作与软件实机记录来自 macOS |

每路 56kΩ 可以用 51kΩ＋5.1kΩ 串联替代，两路需要两套。逻辑分析仪仅为排障辅助，不是日常加载的必备件。

## 固定接线

```text
Mac／扩展坞 USB-A（只供电）
  +5V ───────────────── 测试板 VBUS
       ├── R1 约56kΩ ─── 测试板 A5 / CC1
       └── R2 约56kΩ ─── 测试板 B5 / CC2
  GND ───────────────── 测试板信号 GND
       └──────────────── Pico GND

Pico GP28 ── R3 470Ω ─── 测试板 A侧 D−（A8旁的 D−）
Mac 数据线 ───────────── Pico 数据口（加载后移到相机）
```

两只 56kΩ 分别接 A5、B5，不将 A5/B5 直接短接。USB-A 板 D+/D−、Pico 3V3/VBUS、测试板 A8/B8 及其余未列信号脚留空。相机侧 D− 不能并到 USB-A 的数据脚。测试板翻转／丝印不同时先核实实际节点，金属外壳不能直接当作已确认的信号 GND。

首次搭建或改线后，测试板先不插相机，用万用表相对共用信号 GND 检查 VBUS、A5、B5；空载应接近 5V。这仅为空载检查，不要求插入相机后的 CC 仍为 5V。不要把 5V 直接接入 Pico GP28。线路须固定、裸露接点须绝缘。

## 顺序

1. 相机 OFF、拔普通 USB 线、取电池至少 5 秒；测试板与相机分离。USB-A 供电与 Pico 数据线可接在电脑上。
2. 按 [Fastboot 文档](进入Fastboot.md) 运行检查和注入命令。确认接线后按回车；只有看到 `ARMED: baseline LOW`，才进行下一步。
3. 将测试板插入无电池的相机，再装电池、拨 ON；接线保持不动，等完整 45 条记录发送完成。
4. 收到完整发送／换线提示后，保留电池和 ON 状态；**先从相机拔出整个测试板**，再将数据线从 Pico 端拔下并插到相机。Mac 端不动，测试板与相机保持分离，USB-A 供电端不用拔。
5. 查询 Fastboot 身份和分区表；预期 product=`A6700-AP-read-candidate`。黑屏、闪灯、Pico ACK 均不能代替这一步。枚举失败可先尝试数据线直连 Mac，但没有证据说所有扩展坞都不兼容。
6. 完成维护后，要回到普通拍摄：相机 OFF、断开全部外接线、取电池至少 5 秒，再仅用电池开机。

不能让有电测试板一直插在相机上，仅靠取电池认定已经冷启动。等待上电默认 15 分钟，超时后停止并释放 GP28；超时不是可以自动重试注入的理由。

## 常见卡点

| 情况 | 处理 |
|---|---|
| PING 版本不符 | 停止，核对本地 Pico v2 构建与板型；不跳过版本检查 |
| 载波基线已 HIGH | 不发送；先将测试板离开相机，检查冷启动、共地、残余上拉与接线 |
| 等不到相机上电 | 检查是否在 ARMED 后才插板／装电池，是否误接 SBU |
| 记录未全部完成 | 保留现象；释放、断开、重新冷启动，不从半条流继续 |
| 发送完成却没有 USB | 核对先拔板再换线、电池／ON 是否保持；数据线和端口需支持数据 |
| 身份不匹配 | 不查分区、不尝试其他命令，确认加载了固定只读程序 |

该接法来自个人实机测试，不等同于 USB-C 标准产品设计或已覆盖所有供电条件的硬件方案。后续会补充经核对的实拍，不用其他机型图片冒充 A6700 接线。
