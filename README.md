# Sony A6700 Powerful

给 Sony A6700 增加更多可能的中文社区项目。这里先分享已走通的硬件路线：**用 Pico 进入相机 Fastboot，再通过 USB 读取备份**。

目前仅在 **A6700、2.00 固件、macOS** 上有实机记录。硬件接线与 RAM 载荷已有验证；本次整理后的脚本尚未重新上机。操作可能造成变砖或损坏，并可能影响保修，请先阅读手册。

## 使用教程

1. [硬件说明](硬件说明.md)：采购清单、选购规格、接线图。
2. [操作手册](操作手册.md)：准备工具、进入 Fastboot、备份与退出。

[Pico 与主机源码](源码/) 随教程提供。当前只开放只读路线；固件刷写、全盘恢复待验证后再公开。

## 开发计划与进展

实机已验证 FTP、关机快门帘及静音联动；正在整理普通 USB 解锁／关闭工具，并研究独立曝光、FL2／FL3 等功能。

详见[开发计划与进展](开发计划与进展.md)，分为功能开发计划与开源／一键刷入工具计划。
