# Sony A6700 Powerful

给 Sony A6700 增加更多可能的中文社区项目。这里先分享已走通的硬件路线：**用 Pico 进入相机 Fastboot，再通过 USB 读取备份**。

目前仅在 **A6700、2.00 固件、macOS** 上有历史实机记录。随附本地已用的引导文件，整理版主机脚本已完成离线对照，未新增实机测试。操作可能造成变砖或损坏，并可能影响保修，请先阅读手册。

## 项目构想与 Windows 移植

本项目希望在已验证的只读硬件路线基础上，逐步整理相机功能研究与主机工具，并将公开的 Python 主机流程移植到 **Windows 10/11 x64**。当前已做 Windows 运行环境适配及离线验证，包括 Python 3.12 依赖、固定载荷检查、中文路径文件保存和 libusb DLL 加载；PowerShell 步骤见[操作手册](操作手册.md)。**Windows 的真实 COM 通信、WinUSB 接入、RAM 注入和相机备份链路仍待实机验证**，不代表已完成整条路线移植。

公开内容仍是 Pico 引导、相机 RAM 只读程序及区间备份脚本。桌面应用和普通 USB 解锁／关闭工具尚未公开为可用版本；本次 Windows 适配不代表这些功能已可下载使用。

## 开发计划与进展

实机已验证 FTP、关机快门帘及静音联动；正在整理普通 USB 解锁／关闭工具，并研究独立曝光、FL2／FL3 等功能。

详见[开发计划与进展](开发计划与进展.md)，分为功能开发计划与开源／一键刷入工具计划。
