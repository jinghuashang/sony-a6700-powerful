# USB 运行框架

当前为 0.2.0；CLI、桌面及教程复用同一份运行核心。支持 A6700 2.00 的固定功能字段，不是通用固件写入器。

## 一次设备操作

1. 环境与人工准备检查通过；准备服务不枚举、认证或读写相机。
2. 获取共享设备锁，核对是否存在其他会话；锁与记录目录无关。CLI 锁覆盖整个事务，桌面物理会话从接管前到退出始终持锁，锁内复用事务函数。
3. 校验固定 profile、原生源码和 reader／writer 哈希。macOS 必要时接管唯一目标 MSC 相机，完成两阶段 Senser 认证。默认不复位、不扫描卸载无关磁盘、不整套自动重试。
4. 用新 nonce 上传配置和固定读取器，读取 260 个扇区（133,120 字节）。它涉及临时文件和程序执行，不是完全零写入。
5. 校验所有已知字段、结构守卫及未管理字节哈希。只为用户选中且本版开放的功能生成增量目标；未选字段保持现状，未知内容阻断。
6. `inspect` 与 `--dry-run` 到此为止，不发送功能写入器。实际修改先保存并同步窗口前态、目标和写入意图；记录不能可靠保存则拒绝写入。
7. 相机内写入器重新核对全部前值及固定掩码，逐扇区写入、同步、回读；明确失败时回退已尝试目标。
8. 主机使用新 nonce 和独立读取器核对目标及守卫。写后记录保存失败也继续独立回读，并单独报告记录错误；通信中断不重发写入器。
9. CLI 退出维护服务并释放接口／锁；桌面检查后复用已认证会话，解锁／关闭事务结束即退出会话并释放锁，再显示结果和断电验收步骤。断线使旧兼容结论失效，需重新连接检查。

## 范围与失败处理

- 固定窗口覆盖 App、WBI 与 CP 相关目标及守卫；窗口前态是私人记录，不是完整备份。
- 位移多帧合成、动态增强防抖只保留历史识别，不能写入；“全选缺失”也受发布开关限制。
- 电子快门声音与灵活曝光可分别选择，没有运行时字段依赖。
- `completed` 是写入与独立回读一致，仍需重启验收实际功能。`uncertain`、`verification-failed`、`recovery-required` 需保留记录并排查，不自动重试。
- 退出服务未确认时按提示拔 USB、正常关机重开；操作进行中不得断电或重枚举。
- 稀疏功能状态备份／恢复保留给开发者，桌面入口隐藏；完整备份恢复未实现。明文 USB 视图不直接交给 Pico 密文写入器。
