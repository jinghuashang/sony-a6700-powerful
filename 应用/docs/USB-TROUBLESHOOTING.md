# USB 连接排查

先运行 `a6700-unlock doctor`。它只检查本机环境和包内资源，不表示相机连接或实机适配已经通过。

## 准备连接

仅当已有且开启 FTP 时，停止传输、关闭 FTP 并重启；没有 FTP 菜单可直接继续。接线前选择 MSC（海量存储器）并关闭自动关机，保持唤醒，仅连接一台目标相机。具体菜单路径见 [相机准备图解](CAMERA-PREPARATION.md)。终端运行 `a6700-unlock device inspect`，先验收目标读取，再安排功能写入。

`inspect` 不发送功能写入器；它仍需认证、上传临时配置与读取 ELF，在相机进程中执行读取代码。临时目录不是纯 RAM 保证，不能描述为相机上完全零写入。

## macOS 接管与管理员密码

dev33 起按 Sony 已知 MSC 身份或 MSC 接口描述符发现相机，不先打开 bulk 端点，不要求插有存储卡、存在磁盘卷或存储驱动。已知 MSC 身份在描述符暂不可读时仍保留为候选；实际端点、协议及固件内容在后续检查，不把“找到 MSC”当作适配完成。多台 MSC 相机仍需只保留一台。

默认连接流程只有一次接管和协议必需的两阶段认证，不先恢复驱动、重置 USB 或重复扫描卸载外部磁盘。失败后显示阶段，由用户重新连接，不自动重发整个流程。已安装的本机 helper 若与本版内置组件完全相同，可继续用已有授权；旧 helper 不覆盖新版行为，也不自动改系统 helper 或 sudoers，可能重新出现一次系统授权提示。

内置环境桌面版使用包内已校验的预编译组件，通过系统管理员密码／Touch ID 授权；不需要接收者安装编译器或系统 libusb。源码 CLI 的接管助手在临时目录编译，需要 Command Line Tools、系统 libusb 和终端 sudo 授权。两者都只接管所选相机，不再先扫描卸载存储卷。连接前先关闭访问相机的其他应用。

非交互环境无法提示密码时会立即返回 sudo 错误。在自己的终端运行 `sh start.sh device inspect`，或双击启动工具后选择对应操作。密码直接交给系统 sudo 提示，不写入工具配置或报告。

`--no-capture` 只用于本次连接中接口已被手动接管的情况；它不能绕过系统驱动锁。重新插拔后通常需要再次接管。项目不自动安装永久 root 助手或修改 sudoers。

启动检查只加载 libusb 和检查所需函数，不初始化 USB 上下文。上下文在接管完成后才创建，并在 MSC→服务身份切换后刷新；macOS 接管会改变设备注册状态，提前初始化或长期复用旧枚举上下文可能导致旧进程找不到 MSC，而新进程能找到。若系统仍能看到相机但应用报找不到 bulk 端点，保留阶段信息，先排查进程和接管顺序，不扩大匹配范围或绕过兼容性检查。

授权用于取得维护接口控制权，与普通 MSC 文件访问不同。切换后相机可能不再显示 MSC，而回到拍摄或菜单页面；请保持连接，以应用检查、写入和独立回读的结果判断，不必因画面变化重新插拔。

0.2 修复 USB 上下文／原生设备释放顺序：本地设备、迭代器及父设备包装对象持有所属上下文，先释放设备引用，再释放上下文；刷新缓存不手动提前调用 `libusb_exit`。本机服务中断页可重新启动服务，但不自动接管相机或重放写入。

## 认证超时／退出失败

进度依次显示寻找 MSC、第一次认证、等待服务身份、第二次认证、服务响应确认。报告中的阶段用于定位，不记录原始 ProductInfo。

`dev3` 已修复多组 bulk 端点选择导致第二次认证超时的问题。请先确认运行新版本。若设备进入服务模式后仍超时、或提示退出未获确认，先保留 `result.json`，拔掉 USB、关机重开，再按 MSC 模式连接。不能把仍显示 Sony USB Device 的服务身份当作正常 MSC，连续盲试也不会修复接口状态。STOP 的管道错误可能来自身份切换；工具会独立枚举，只有观察到唯一 MSC 才记录 `msc-observed`，否则提示人工处理。

尚未发送写入器时报告 `write_attempted=false`；只读预检失败不能推断功能已修改。写入请求发送后丢失结果则是 `uncertain`，应先核实当前状态，工具不会自动重发。

操作明确完成后按结果页关机、断开 USB／其他外接供电、拔出电池、至少等待 10 秒、插入电池再开机检查。不要在写入或回读期间执行。

## 操作互斥

桌面已认证会话从接管前到退出始终持锁；保持连接期间其他工具需要等待，使用结束后退出相机模式或关闭应用释放会话。CLI 每次操作沿用同一共享锁。设备锁位于本机用户状态目录的 `sony-a6700-ftp/.assistant.lock`，与研究向导共用。更换 `--state-dir` 不绕过设备锁；锁文件保留，通过文件句柄持锁，不能靠删除锁文件解除忙状态。

## 内容或布局不匹配

`blocked` 表示完整字段、扇区或布局守卫不符合已知适配。没有强制写入开关。先保留报告并核对机型、固件、历史修改；本次窗口前镜像也不是全盘备份。当前仅适配已知 A6700 2.00 布局，实时 WBI 差异仍需实机排查。

公开反馈可提供错误阶段与脱敏后的 `result.json`。先移除本机路径等个人信息；不要上传 `preimages.json`、`targets.json`、原始 ProductInfo 或整机备份。
